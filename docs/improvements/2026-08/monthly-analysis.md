# 선택 월 통계 개선

> 작업일: 2026-08-20

## 문제

- 기존 동작: 카테고리 통계는 시스템 현재 월만 집계하고 월별 추이는 거래가 있는 달만 표시했다.
- 문제점: 홈에서 과거 월로 이동해도 분석 화면은 같은 월을 분석할 수 없었고 빈 달이 차트에서 누락됐다.
- 사용자 영향: 월별 소비 구성과 연속적인 지출 추세를 정확하게 비교하기 어려웠다.

## 원인

- 원인: 통계 API와 분석 화면에 선택 월 상태가 없고 집계 결과에서 데이터가 없는 달을 생성하지 않았다.
- 관련 파일/API/DB: `frontend/src/screens/AnalysisScreen.tsx`, `frontend/src/lib/api.ts`, `GET /expenses/analysis/category`, `GET /expenses/analysis/monthly`

## 수정

- 변경 내용: 분석 화면과 통계 API를 선택 월 기준으로 확장했다.
- 변경 파일: `AnalysisScreen.tsx`, `api.ts`, `expenses.py`, `date_utils.py`
- 주요 로직 변경:
  - 카테고리 통계에 `year`, `month`, `tab` 조건 전달
  - 분석 화면에 이전·다음 월과 이번 달 이동 추가
  - 선택 월을 마지막 달로 하는 연속 6개월 생성
  - 거래가 없는 달도 `amount: 0`으로 반환
  - 차트의 월을 누르면 해당 월 홈 장부로 이동
  - AI는 현재 월 전용으로 유지하고 제목을 `이번 달 AI 인사이트`로 명시
